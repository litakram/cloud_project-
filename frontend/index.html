LearnAPI frontend

Single-file interface for auth, courses, lessons, and progress.

A plain HTML + vanilla JS frontend with no build step. It saves the JWT in localStorage, works with your four service URLs, and gives you a clean browser UI for registration, login, course enrollment, lesson viewing, and progress tracking.

Fast path: open this file in a browser or serve it statically

What this frontend covers
1. Auth page for register and login, with JWT saved to localStorage.
2. Course catalog with public listings, create-course controls, and enroll actions.
3. Lesson viewer for enrolled courses, with lesson content and completion tracking.
4. Progress dashboard grouped by course.
